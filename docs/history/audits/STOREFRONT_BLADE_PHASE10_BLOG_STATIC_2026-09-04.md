# 3. Blog Routes

- `GET /blog` (`storefront.blog.index`)
- `GET /blog/{post}` (`storefront.blog.show`), resolved by stable slug through the public query layer.

- Static pages: `/about`, `/contact`, `/faq` with named routes `storefront.about`, `storefront.contact`, and `storefront.faq`.

# 4. Blog Query

`StorefrontBlogQuery` centralizes published visibility, newest-first `published_at` ordering, category filtering, title/excerpt/content search, bounded pagination, taxonomy loading, slug lookup, and deterministic same-category related posts excluding the current article.

# 5. Blog Listing

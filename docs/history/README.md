# Historical Documentation

Status: Historical / Non-authoritative
Last reviewed: 2026-09-07
Applies to: Historical evidence only

The reports in this tree preserve prior QA, implementation, incident, migration, and audit evidence. They are intentionally retained, but their conclusions may describe an earlier repository state. Current rules belong in the canonical pages under `docs/`, `README.md`, and `AGENTS.md`.

## Classification

- `audits/`: QA, phase, parity, readiness, cache, payment, settings, demo, and scalability reports.
- `incidents/`: recovery and runtime failure records.
- `migrations/`: controlled data reconstruction records.
- `archived-docs/`: reserved for superseded documents that are not deleted until redundancy is confirmed.

Historical reports may mention old paths, test totals, or temporary development values. Do not use them as current operational instructions without checking the code and canonical documentation.

# Browser Tests

Status: Canonical
Last reviewed: 2026-09-07
Applies to: Current repository

Playwright is the browser-level tool for visual and interaction proof. Browser tests must use safe isolated data, never live provider sends, and should target high-value flows such as storefront catalog, auth/cart, checkout/payment boundary, and blog. A PHP test that asserts HTML is not browser evidence. Keep screenshots/traces out of source control unless they are intentional evidence artifacts.
